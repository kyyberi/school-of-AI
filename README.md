# School4AI / Hoc vien AI

Plain static bilingual website for the School4AI / Hoc vien AI community learning idea starting in Yên Bái, Vietnam, with the aim of growing into more locations.

## Files

- `index.html` is the Vietnamese default page.
- `en.html` is the English page.
- `css/styles.css` contains the responsive layout and visual styling.
- `assets/` contains logos, illustrations, favicon, and social preview assets.

## Editing

Open `index.html` directly in a browser or upload the folder to any static web server.

The intended custom domain is `school4ai.net`.

There is no JavaScript app, install step, build command, backend, form, account system, or database.
